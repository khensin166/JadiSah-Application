# Frontend Structure

- `app/`: Next.js App Router routes (e.g., `(auth)`, `dashboard`, `wedding`).
- `components/`: Reusable UI components (shadcn/ui goes here).
- `hooks/`: Custom React hooks.
- `lib/`: Utility functions, API clients, Zod schemas.
- `types/`: Global TypeScript definitions.
- `public/`: Static assets.
